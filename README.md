# 🎮 PSX TERROR GAME - A Retro PSX-Style 3D Game  

![Godot 4.3](https://img.shields.io/badge/Godot-4.3-blue?style=flat&logo=godot-engine)  
*A 3D game inspired by classic PlayStation 1 aesthetics, built with Godot 4.3.*  

## 📜 About the Project  
PSX TERROR GAME is a **low-poly, retro-styled 3D game** inspired by the PS1 era. Designed with **Godot 4.3**, this game delivers nostalgic visuals, atmospheric lighting, and fluid gameplay.  

**⚔️ Game Genre:** *(Survival Horror, FPS, Adventure)*  
**🕹️ Gameplay:** *(Exploration, Combat, Puzzle-solving)*  

> *"Bringing back the charm of retro gaming with modern tools!"*  

## 🎮 Features  
✅ **PSX-style low-poly graphics** (distorted textures, limited colors)  
✅ **Smooth 3D movement & physics**  
✅ **Immersive atmosphere & lighting**  
✅ **Retro-style sound effects and UI**  

## 🛠️ Built With  
- **Godot 4.3** – Open-source game engine  
- **GDScript** – Scripting language for Godot  
- **Blender** – For 3D modeling (optional)
